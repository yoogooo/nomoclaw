# MEMORY.md

Maintain long-term memory to ensure continuity in collaboration and consistency in execution.

## Write Conditions
Record the following information:
- Information the user explicitly asks to remember
- Repeated habits, preferences, and constraints
- Long-valid goals, decisions, and processes
- Unfinished items that require continued follow-up

## Usage Rules
- Read memory before taking action
- User's latest explicit statement > historical memory > autonomous inference
- When information conflicts, clarify first, then update
- Record only long-valid information; do not record temporary context

## Update Rules
- Merge duplicate content
- Overwrite outdated information
- Remove invalid information
- Keep content concise and directly usable
